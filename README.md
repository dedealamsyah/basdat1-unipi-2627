# Portal Materi Basis Data UNIPI

Selamat datang di portal materi Basis Data untuk Program Studi S1 Informatika, UNIPI. Portal ini dirancang untuk memberikan pengalaman pembelajaran yang interaktif dan komprehensif, dengan fokus pada materi inti dan praktik langsung.

## Struktur Proyek

- `index.html`: File utama yang memuat antarmuka pengguna. Tidak disarankan untuk diedit secara langsung kecuali Anda memiliki pemahaman mendalam tentang HTML/CSS.
- `app.js`: Logika aplikasi untuk rendering materi dan interaktivitas. File ini otomatis membaca `content.js` dan tidak perlu diedit.
- `content.js`: **Satu-satunya file yang perlu diedit** untuk menambah atau memodifikasi materi perkuliahan. Ikuti petunjuk di dalam file ini untuk menambahkan pertemuan baru.
- `docs/`: Folder ini berisi dokumentasi tambahan mengenai pengembangan dan panduan penggunaan.

## Cara Menggunakan

1.  **Unduh atau Clone** seluruh repositori ini ke komputer lokal Anda.
2.  **Buka file `index.html`** langsung di browser web favorit Anda (Chrome, Edge, Firefox, dll.). Tidak diperlukan koneksi internet atau server web untuk menjalankan portal ini.
3.  Materi Pertemuan 1 dan 2 sudah tersedia dan dilengkapi dengan fitur interaktif. Pertemuan lainnya masih dalam status 'Belum Tersedia' dan dapat diaktifkan melalui `content.js`.

## Fitur Utama

- **Navigasi Intuitif:** Sidebar yang menampilkan daftar pertemuan dengan indikator progres.
- **Konten Interaktif:** Simulasi, kuis, dan visualisasi diagram untuk memperdalam pemahaman konsep.
- **Diagram Interaktif dengan Zoom:** Setiap diagram penting dilengkapi fitur zoom in/out, reset, dan pan untuk memudahkan eksplorasi detail.
- **Responsif:** Desain yang dioptimalkan untuk tampilan di berbagai perangkat (PC/laptop, tablet, smartphone).
- **Referensi Akademik:** Setiap konsep yang disajikan didukung oleh referensi dari literatur basis data terkemuka.

## Kontribusi Materi

Untuk menambahkan atau memperbarui materi, cukup edit file `content.js`. Pastikan untuk mengikuti struktur objek `PERTEMUAN` dan `sections` yang telah ada. Informasi lebih lanjut dan panduan penulisan dapat ditemukan di `docs/README.md`.

## Kontak

Untuk pertanyaan lebih lanjut atau saran, silakan hubungi tim pengembang atau buka issue di repositori GitHub ini (jika ada).
