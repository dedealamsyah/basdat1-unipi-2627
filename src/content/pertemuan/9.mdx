## E. Instalasi & Konfigurasi Awal DBMS

### E.1 Pilihan Alur Instalasi

Ada tiga jalur umum untuk mulai memakai DBMS:

| Jalur | Cara Bergerak | Cocok Untuk |
|---|---|---|
| **Aplikasi paket (XAMPP)** | Sekali instal, langsung dapat Apache + MySQL/MariaDB + PHP | Startup tercepat, Windows/macOS/Linux |
| **Installer DBMS murni** | Instal MySQL/PostgreSQL tersendiri | Memahami detail konfigurasi |
| **SQL online / portabel** | Tidak perlu instal; jalankan di browser (DB Fiddle, SQLite Online, atau SQL Playground portal ini) | Smartphone / uji cepat |

<div class="callout callout--amber">
  <span class="callout__label">Untuk Praktikum Ini</span>
  <p>Ikuti jalur paling cepat sesuai perangkat Anda. Di laboratorium, gunakan <strong>XAMPP</strong> (berisi MySQL/MariaDB). Jika memakai smartphone atau tidak sempat instal, buka <strong>SQL Playground</strong> portal ini atau DB Fiddle/SQLite Online untuk latihan perintah yang sama.</p>
</div>

### E.2 Langkah Instalasi XAMPP (Ringkas)

<ol class="steps">
  <li>Unduh XAMPP dari situs resmi (Apache Friends) sesuai sistem operasi Anda (Windows/macOS/Linux).</li>
  <li>Jalankan installer, ikuti default. Pada Windows, selesaikan hingga proses instalasi selesai.</li>
  <li>Buka <strong>XAMPP Control Panel</strong>, lalu klik <strong>Start</strong> pada modul <strong>MySQL</strong> (dan Apache bila diperlukan).</li>
  <li>Tunggu status berubah menjadi <strong>Running</strong>; port default MySQL adalah <code>3306</code>.</li>
  <li>Buka browser ke <code>http://localhost/phpmyadmin</code> untuk mengakses MySQL via GUI, atau gunakan <strong>Shell</strong> pada Control Panel untuk mode CLI.</li>
</ol>

<div class="callout">
  <span class="callout__label">Catatan Praktis</span>
  <p>Pada XAMPP, akun default MySQL adalah <code>root</code> dengan <em>password kosong</em> (atau sesuai setelan Anda). Selalu ganti password pada praktik nyata. Port <code>3306</code> adalah <em>default</em> untuk MySQL, sementara PostgreSQL memakai <code>5432</code>.</p>
</div>

## F. Akses DBMS melalui CLI dan GUI

DBMS dapat diakses dengan dua cara utama: baris perintah (CLI) dan antarmuka grafis (GUI).

### F.1 Akses CLI (Command Line Interface)

CLI memberi Anda kontrol penuh dan banyak dipakai programmer. Contoh pada terminal/laravel di lingkungan yang sudah aktif:

```bash
# Masuk ke shell MySQL sebagai pengguna root
mysql -u root -p

# Representasi di PostgreSQL
psql -U postgres

# Melihat daftar basis data
SHOW DATABASES;
```

### F.2 Akses GUI (Graphical User Interface)

GUI memudahkan pemula karena semuanya terlihat. Pilihan umum:

| Antarmuka | DBMS | Kegunaan |
|---|---|---|
| **phpMyAdmin** | MySQL/MariaDB | Bawaan XAMPP, berbasis browser |
| **MySQL Workbench** | MySQL | Desain visual + editor query |
| **pgAdmin** | PostgreSQL | Manajemen + shell query |
| **DBeaver** | Banyak DBMS | Universal, mendukung banyak DBMS |

<div class="callout">
  <span class="callout__label">Tips Praktikum</span>
  <p>Gunakan <strong>GUI</strong> untuk memahami struktur: melihat tabel, isi data, dan relasi secara visual. Gunakan <strong>CLI</strong> untuk mengetik perintah SQL langsung, yang lebih dekat dengan cara kerja saat Anda menulis program. Kuasai keduanya: mahasiswa yang dapat menulis di CLI umumnya lebih memahami logika SQL.</p>
</div>

## G. Studi Kasus: Basis Data "Akademik_UNIPI"

Mari terapkan hal di atas untuk membangun basis data sederhana pertama kita, hasil implementasi dari PDM yang dirancang di Pertemuan 7.

### G.1 Membuat dan Menggunakan Basis Data

```sql
-- Buat basis data baru
CREATE DATABASE akademik_unipi;

-- Aktifkan basis data tsb. sebagai default
USE akademik_unipi;

-- Karena belum ada tabel, cek hasilnya
SHOW TABLES;   -- (kosong, belum ada tabel)
```

<div class="callout callout--amber">
  <span class="callout__label">Hubungan dengan Pertemuan Sebelumnya</span>
  <p>Perintah <code>CREATE TABLE</code> yang sudah Anda tulis sebagai <strong>DDL PDM</strong> di Pertemuan 7 kini akan dieksekusi pada <em>DBMS sungguhan</em>. Nama database di atas hanyalah contoh; gunakan nama proyek kelompok Anda.</p>
</div>

### G.2 Uji Coba di SQL Playground

Tidak sempat menginstal? Coba langsung di **SQL Playground** portal ini (berbasis SQLite). Perbedaan kecil pada SQLite: tidak ada `SHOW DATABASES` (file basis data dibuat otomatis), dan `USE` tidak diperlukan.

> **Perhatikan:** Playground sudah memuat data contoh sederhana, termasuk tabel `mahasiswa` (berisi `nim`, `nama`, `prodi`, `angkatan`). Jangan membuat ulang tabel yang sudah ada, inilah penyebab error "table mahasiswa already exists". Gunakan **nama tabel baru** untuk mencoba `CREATE TABLE`.

Buka [SQL Playground](/playground) lalu coba tahapan berikut:

**1) Akses data yang sudah tersedia (DML, seperti SELECT di CLI/GUI):**

```sql
-- Lihat isi tabel yang sudah ada di playground
SELECT * FROM mahasiswa;
```

**2) Buat tabel baru dengan DDL (nama unik agar tidak bentrok):**

```sql
CREATE TABLE catatan (
  id    INTEGER PRIMARY KEY,
  judul TEXT NOT NULL
);

INSERT INTO catatan (judul) VALUES
  ('latihan DDL Pertemuan 9'),
  ('persiapan proyek tahap 2');

SELECT * FROM catatan;
```

<div class="callout">
  <span class="callout__label">Ingat</span>
  <p>Sintaks <code>CREATE DATABASE</code>/<code>USE</code> dan <code>SHOW DATABASES</code> bersifat spesifik MySQL/PostgreSQL dan tidak berlaku di SQLite. Namun <strong>DDL &amp; DML</strong> (<code>CREATE TABLE</code>, <code>INSERT</code>, <code>SELECT</code>) hampir identik, hanya tipe datanya yang menyesuaikan (mis. <code>TEXT</code> menggantikan <code>VARCHAR</code>).</p>
</div>

## I. Rangkuman

- Pertemuan 9 menandai peralihan ke **tahap implementasi** basis data dengan DBMS nyata
- Jenis DBMS: MySQL, MariaDB, PostgreSQL, SQLite, SQL Server, Oracle; masing-masing punya kekhasan
- Bahasa basis data: **DDL, DML, DCL, TCL**
- DBMS diakses melalui **CLI** (`mysql -u root -p`) atau **GUI** (phpMyAdmin, MySQL Workbench, pgAdmin)
- XAMPP adalah paket cepat untuk memulai MySQL/MariaDB (port default 3306)
- Buat basis data dengan `CREATE DATABASE` lalu aktifkan dengan `USE`
- Latihan tanpa instal: gunakan **SQL Playground**, DB Fiddle, atau SQLite Online
